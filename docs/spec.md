## 最新已确认方向（2026-11-05）

- 面向海外客户，主要用户为海外采购商；默认语言为英文，语言种类对齐参考站。当前参考站语言菜单观察到 13 种：英语、希伯来语、荷兰语、法语、意大利语、西班牙语、葡萄牙语、希腊语、简体中文、罗马尼亚语、俄语、泰语、土耳其语；具体地区变体和翻译质量仍需确认。
- 首期按参考站的栏目及整体风格建设完整的页面与组件结构；具体文字、图片与功能数据可先使用明确标记的示例。此前作物指南“先保留示例入口”的决定，按新要求扩展为先建设对应页面与结构示例，真实作物指南内容和技术资料仍待提供。
- 产品、图片、新闻由项目方维护，需要后台直接调整；用户不需要内容审核工作流。用户确认后台选用 Payload + Next.js、正式环境使用 PostgreSQL、本地开发使用 SQLite；PostgreSQL 和生产部署仍需验证。账号访问控制、备份和正式内容准确性仍是独立问题。
- 服务器、域名、品牌资料和原始画册已在当前交接中落地；未授权第三方素材仍不得视作可用于正式上线的业主素材。
- 用户要求前后端关联一致：应按内容模型、语言版本和稳定标识贯通后台编辑、前台展示和后续替换。当前前台提供中英文原型；Payload 产品、分类、媒体、新闻和知识文章已进行有限本地接入验证，其他前台语言及真实内容仍未完成。

## 目标与范围

参考 Haifa 的公开页面，构建可编辑的化肥品牌导购网站，覆盖主要页面类型及关键交互。先完成可对照原型，再接入经业主核对的资料、真实多语言内容与联系功能。研究素材和示例数据仅用于原型，正式素材须核实使用权。

## 页面与体验

范围：按参考站继续盘点并建设全部栏目及页面类型，包括首页、产品、方案、作物指南、企业、文章、案例、新闻、联系、FAQ 和其他观察到的栏目；交互与第三方服务逐项识别、实现或明确标注待接入。参考站的具体数据、素材和服务端实现不能自动获得。

当前示例方案不是完整作物指南；不得将未经确认的施肥建议或产品适用关系展示为业主事实。

## 数据与语言

2026-11-06 用户确认：知识文章、新闻和案例正文需要富文本，支持标题、列表、链接与图片；现有纯文本需迁移保留，并验证多语言、前台渲染、搜索、媒体关联和数据迁移。

后续已为三类内容增加 Payload Lexical 富文本和前台渲染，保留纯文本字段用于搜索与兼容。PostgreSQL 增量迁移会按语言将既有纯文本转换为段落；SQLite 旧内容读取时转换为可编辑内容。三类示例的正文显示和搜索、一个媒体插图、中英文新闻、后台旧文编辑，以及带旧数据的 PostgreSQL 迁移已做隔离验证；知识文章后台的标题、无序列表及外部链接也已实测。其他语言、其他内容类型的完整编辑流程、生产数据迁移及正式部署仍未验收。回滚富文本字段会丢失富文本排版及图片关联，生产迁移与回滚前需做好数据库及媒体备份。

产品字段至少考虑名称、分类、图片、规格、成分、说明、应用场景和翻译。示例数据须标识。界面文案与内容翻译分别维护；用户已确认各语言统一使用前缀，原型现将 `/` 跳转 `/en`，中文使用 `/zh`，原中文内页保留临时兼容跳转；完整语言、缺译处理与 SEO 策略待定。技术参数和译文的事实准确性需由资料提供方确认，不要求建立后台审核工作流。
