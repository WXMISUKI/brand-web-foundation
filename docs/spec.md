# 化肥导购独立站规格草案

状态：草案；2026-11-05 用户确认自主建立轻量 Next.js 项目，复用 JCodesMore 观察和逐页对照方法；目标市场、语言及正式功能待确认。

## 目标与范围

参考 Haifa 的公开页面，构建可编辑的化肥品牌导购网站，覆盖主要页面类型及关键交互。先完成可对照原型，再接入经业主核对的资料、真实多语言内容与联系功能。研究素材和示例数据仅用于原型，正式素材须核实使用权。

## 页面与体验

候选：首页、产品分类及列表、产品详情、企业介绍、联系，以及调研发现后确认的其他主要页面类型。导航、语言切换、筛选、轮播及响应式行为以调研清单和最终确认范围为准。相同类型的海量内容不逐条复刻。

## 数据与语言

产品字段至少考虑名称、分类、图片、规格、成分、说明、应用场景、翻译、发布状态。示例数据须标识。界面文案与产品翻译分别维护；语言 URL、缺译处理及目标语言待决定。业主审核配方与译文。

## 验收与边界

原型：选定页面在桌面和移动端可浏览，与参考站相同视口对照，关键交互可操作，未实现功能如实标记。数据及语言：使用多条数据验证列表、详情、筛选、切换、刷新和直接访问。正式站：真实内容审核，询盘与维护流程实际验证，列出已知问题。不得将原型或自动评分视为上线验收。

正式技术栈、CMS、部署方式和语言策略尚未决定；各方案的架构与工作量差异需提交用户确认。生产发布另行确认。遵守现有访问限制，不绕过登录或验证码。保留研究和正式资产的来源与授权状态。

## 待业主确认

目标市场和语言；客户类型及询盘渠道；上线产品清单和参数；品牌及素材授权；内容更新人员、频率与后台需求；域名部署和上线时间。
