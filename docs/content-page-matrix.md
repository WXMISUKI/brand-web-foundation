## 共性验收结果

- 以上页面在 1280 × 720 下均未出现根横向溢出。
- 方案、FAQ、新闻、知识、案例、搜索和 SDS 资源页在 390px 移动视口下均未出现根横向溢出，布局 clientWidth 为 375px（滚动条占用宽度）。
- 方案、FAQ、知识、案例和资源页面复用详情布局与右侧联系入口；列表类页面复用筛选、分页和语言路径构造器。
- 新闻、知识、案例正文统一经过 `RichBody` 渲染，保留纯文本兼容回退。
- 语言切换不会静默回退到另一语言的正文；缺译显示待补充文本。
- 业主真实内容接入时，优先替换 Payload 数据和媒体字段，不应重新编写页面组件。
- 新闻、知识文章和案例当前共用 `src/data/content-staging.json` 作为多语言 staging 来源，字段对应 Payload 的 `slug/title/summary/author/publishedOn/image` 契约。

3. 对 FAQ 分类切换、筛选表单、分页和详情页补齐 390/320 移动视口实测。
