# 业主资料填写说明

这些表格用于收集首批网站资料，可用 Excel 或其他表格软件打开后填写；保存时请保留 UTF-8 编码。也可以直接提供已有的产品表和原始技术资料，不必重复整理。本模板不是网站后台的导入格式，填写后仍需核对、整理并决定导入方式。

1. `products.csv`：每款产品或需独立展示的规格填写一行。`产品编号`由业主选用已有稳定编号；不同文件使用相同编号关联。未确认的项目留空，不填猜测值。
2. `specifications.csv`：同一产品每项检测指标填写一行；数值、单位、上下限按经审核的原始资料填写，保留原文和来源版本，不自行换算。没有适用上限或下限时请写明原因，不要默认为零。
3. `assets.csv`：每张包装图、Logo、证书、视频或下载文件填写一行，文件本身另行提供。填写可公开范围、授权情况和有效期；证书须确认仍然有效。
4. `business-answers.md`：填写市场、语言、联系方式、维护与首期范围；不确定时保留“待确认”。

产品中文及英文文案、适用作物、用法用量、产品指标和宣传表述需要由业主相应负责人审核。外文缺失可留空并标记待翻译；未经审核不作为正式译文发布。图片和文件请提供原始文件或可访问的共享位置，表内引用文件名即可。
