# 询盘治理闸门（2026-11-10）

状态：业主已确认继续 Payload 后台人工处理；邮件/工单通知、自动删除和持久化限流均不配置，也不对外承诺 SLA。本文保留 honeypot-only 和隐私责任边界。

## 当前证据

| 能力 | 状态 | 证据 | 结论边界 |
| --- | --- | --- | --- |
| 开关控制 | PASS-SCOPED | `INQUIRY_MODE=disabled` 返回 `503 inquiry_disabled`；启用后才访问 Payload | 不代表生产通知或人工响应已自动化 |
| 字段校验 | PASS-SCOPED | 姓名、邮箱、留言、consent 必填；长度有上限；locale/sourcePath 受限 | 不代表内容已做 PII 分类或敏感信息过滤 |
| 反垃圾基础门禁 | PASS-SCOPED / LIMITED | 隐藏 `website` honeypot 非空时拒绝 | 目前没有持久化 IP/设备速率限制、验证码或外部反垃圾服务 |
| 公开访问边界 | PASS-SCOPED | 公开接口只创建；读取、修改、删除需要管理员 | 不代表管理员最小权限、审计日志和导出策略已完成 |
| 状态流转 | PASS-SCOPED | `new`、`in-progress`、`qualified`、`closed`、`spam` | 不代表状态处理有固定 SLA |
| 同意记录 | PASS-SCOPED | `consent=true` 才允许创建，记录保存在 Payload | 隐私文本版本、法律依据和撤回流程仍待确认 |
| 通知 | NOTIFY-LIMITED | 当前成功只代表 Payload 记录成功；Contact 提供邮箱/WhatsApp | 不得声称邮件或工单已送达 |

## 2026-11-10 生产边界复核

- 公网 `GET /api/inquiries?limit=1` 返回 `403`；匿名读取边界与产品 API 一致。
- `/api/ready` 返回 200 且 database/media 均为 true；`/api/health` 返回 production/postgres/payload 形状。
- 业主选择的当前范围为“写入 Payload、后台人工处理、不接 SMTP/CRM、不配置自动删除/限流、不承诺 SLA”。该范围已实现并验证；honeypot-only、无自动删除和无速率限制是明确的范围边界。

## 当前生效运营方式

- 所有 Payload 后台账号均可查看和处理询盘；当前由常驻后台人员留意。
- 没有固定检查频率、首次响应 SLA 或自动通知承诺。
- 业主已明确继续人工后台处理，不接入 SMTP/CRM，不把后台写入描述为邮件送达。
- 询盘成功文案必须表述为“已记录，可在后台查看”，不能表述为“已发送邮件”。
- 生产数据不执行未经确认的批量删除、匿名化或导出。

| 决策项 | 当前值 | 影响 |
| --- | --- | --- |

| PII 保留期限 | 未确认 | 定期删除/匿名化任务、备份保留和恢复后的清理 |
| 删除或匿名化责任人 | 未确认 | 后台操作权限、审批和误删恢复 |
| 速率限制 | 未确认 | 单 IP/邮箱/设备阈值、窗口、429 文案和代理头信任边界 |
| 验证码或外部反垃圾服务 | 未决定 | 成本、隐私、可用性和外部账号依赖 |

| 响应时限 | 无对外承诺 | 不能在页面或自动回复中暗示 SLA |

## 后续阶段闸门

### I1：治理决策

- 当前状态：`PARTIAL / WAITING-EXTERNAL`。
- 通过条件：隐私版本、保留期限、删除责任人、速率限制、通知策略和是否设置 SLA 均有明确记录。

### I2：反垃圾与访问保护

- 前置条件：速率限制阈值和代理头信任边界已确认。
- 验收：正常提交仍为 201；超过阈值返回 429 并带 `Retry-After`；honeypot、无 consent、非法邮箱仍被拒绝；不得记录完整 PII 到日志。
- 未满足前：保留当前 honeypot-only 的 `PASS-SCOPED / LIMITED` 结论。

### I3：保留、删除与审计

- 前置条件：保留期限、法律依据、删除责任人和备份清理关系已确认。
- 验收：隔离库演练创建、状态处理、匿名化/删除和管理员回读；生产变更前必须有 PostgreSQL/media 备份和回滚方案。

### I4：通知适配器（可选）

- 前置条件：业主明确需要 SMTP 或工单服务，并提供收件/失败重试/回执策略。
- 验收：只在 Payload 写入成功后发送；失败状态可见；重试幂等；秘密不写日志；独立验证送达。
- 没有明确授权前：保持人工后台处理，不接入外部通知。

## 禁止扩大结论

- 201 只证明记录写入，不证明邮件送达、人工已查看或已回复。
- honeypot 通过不等于完整反垃圾能力。
- 管理员可查看不等于已满足最小权限、隐私合规或保留期限。
- 备份存在不等于已完成 PII 删除或备份同步清理。
