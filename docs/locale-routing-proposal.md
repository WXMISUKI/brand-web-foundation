## 现状与目标

迁移前中文使用 `/`、`/products` 等无前缀地址，英文使用 `/en`、`/en/products`；这与已确认的“默认英文、各语言独立 URL”不一致。原型现已实施方案 A，正式 SEO、自动语言识别和缺译策略另行确认。当前仍为原型并禁止索引。

## 方案 A：全部语言使用前缀（推荐）

`/` 跳转 `/en`；英文 `/en/...`，中文 `/zh/...`。原无前缀中文内页跳转到对应 `/zh/...`，保留查询参数。所有语言结构一致，扩展其他语种较直接；根地址由中文改为英文是有意的行为变化。

## 方案 B：英文无前缀

`/`、`/products` 等对应英文，中文使用 `/zh/...`，已有 `/en/...` 跳转到对应英文地址。短英文 URL 较简洁，但当前无前缀中文内页与未来英文内页占用同一地址：旧链接无法仅凭路径判断用户想访问中文还是英文，需要明确兼容策略。
