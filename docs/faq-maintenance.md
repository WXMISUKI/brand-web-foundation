# 常见问题维护（原型）

本说明基于本地隔离后台的英文界面操作，正式服务器、账号和访问地址尚未确定。后台录入的内容会在 `CATALOG_SOURCE=payload` 的前台显示；默认示例模式不会读取后台内容。

1. 登录后台，在 **FAQ categories** 新建分类。填写唯一的 `Slug`（稳定标识）和分类名称，必要时填写排序值；数值越小越靠前。
2. 在 **FAQs** 新建问题，选择分类，填写问题、回答和排序值后保存。目前回答是纯文本。
3. 刷新对应语言的前台常见问题页，选择分类并展开问题，核对展示内容。分类、问题或回答缺译时会提示待翻译。
4. 后台顶部的 Locale 用于选择要编辑的语言；其他语言的实际录入流程仍需在正式环境逐项验证。切换语言不自动翻译或校对内容。
5. 删除分类前先移动或删除其关联的问题；删除内容前应按实际运维方案完成备份。

本地隔离验证走通了英文分类和问答的后台创建、关联保存及前台展开；中文内容此前通过 API 验证，尚未验证后台界面的中文录入流程。页面仍为原型，正式内容需业主核对。
