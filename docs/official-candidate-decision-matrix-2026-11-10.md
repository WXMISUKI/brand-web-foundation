## 每条候选必须补齐的字段

| 字段 | 业主需要确认 | 放行规则 |
| --- | --- | --- |
| 展示决策 | keep-separate / merge / exclude / needs-source | 未填写保持 `owner-review` |
| canonical / alias | 合并时指定唯一 canonical 与 alias 列表 | 不得按名称自动合并 |
| 稳定 SKU / 型号 | 标签、包装或销售资料中的正式值 | 缺失时不生成型号 |
| 包装规格 | 净含量、包装形式、适用市场 | 不从图片比例推断 |
| 定量规格 | 数值、单位、典型/最小/最大值及来源 | 无可靠来源保持空，不引用 Haifa 或相邻产品数值 |
| claims | 逐条确认效果、成分、适用作物、认证等表述 | 全部确认后才可 `claimsVerified=true` |
| 销售状态 | 在售、停产、区域限定或待确认 | 待确认不进入公开产品目录 |
| 分类 | 水溶肥、中量元素、复合肥等正式分类 | 不能只按名称猜测 |
| 图片授权 | 业主素材、官方来源、授权示例或禁止使用 | 未确认的图片不作为正式主图 |
| 英文/中文及其他语言 | 最终名称、短简介、规格标签和术语 | AI 草稿必须经过人工审校 |
| 签核记录 | 签核人、日期、来源文件或链接 | 缺签核不进入发布批次 |
