# 化肥导购网站原型

这是参考 Haifa 页面结构开发的中英文导购网站原型，使用 Next.js App Router、React 和 TypeScript。当前品牌、产品、译文与图片均为示例；询盘发送、内容后台、真实产品数据及正式上线验收尚未完成。页面目前设置为不被搜索引擎收录。

## 本地启动

建议使用 Node.js **22.19.0**（见 `.nvmrc`，也是项目最低要求）。当前开发机已安装该版本，但全局曾检测为 22.16；可在终端使用已有版本管理器执行 `nvm use 22.19.0` 后确认 `node --version`。本机曾以 22.19 启动开发服务并打开英文产品页；完整生产构建曾使用 Node 24.22.2，最终版本仍需在目标运行环境验证。

在项目目录执行：

```sh
npm ci
npm run dev
```

浏览器访问启动日志给出的本地地址，通常为 `http://localhost:3000`。需要其他端口时可使用 `npm run dev -- -p 3118`。`npm run typecheck` 用于类型检查。

生产模式验证可按需执行 `npm run build`，再运行 `npm run start`。历史上曾对某个先前版本执行过生产构建和局部浏览器检查；后续修改可能使其过期，上线前须针对最终版本重新验证。

## 当前原型入口

- 中文首页 `/`、产品目录 `/products`、企业介绍 `/about`、联系页 `/contact`。
- 英文首页 `/en`，对应产品目录 `/en/products`、企业介绍 `/en/about`、联系页 `/en/contact`。
- 产品及作物/种植方式示例详情使用各自路径；产品列表的 `category` 参数保留筛选状态。中英文页面之间提供切换入口。

具体产品字段和资料目前在 `src/data/` 中以示例形式维护；图片与参数结构可接入资料，但还没有后台或自动批量导入。实际产品、功效、用量和译文需业主审核后才可用于正式站。

## 项目资料

- `docs/spec.md`：规格草案与范围。
- `docs/reference-research.md`：参考页面观察及未验证项。
- `docs/prototype-status.md`：阶段进度、测试范围及限制。
- `docs/owner-questions.md`、`docs/owner-templates/`：业主待确认问题和资料收集模板。
- `docs/content-i18n-acceptance.md`：内容与多语言验收草案。

正式发布前还需确认目标市场、语言、域名、素材授权、真实产品资料和询盘接收方案，并完成针对最终版本的功能、视觉、设备及部署验收。
