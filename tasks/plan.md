# Haifa 参考站复刻执行方案

更新时间：2026-11-09

## 目标

先完成参考站主要页面类型、共享导航、关键交互和响应式结构的可对照复刻；所有业主资料继续通过 Payload 数据模型接入，后续只替换内容、媒体和配置，不重写页面骨架。

## 当前判断

- 技术底座：Next.js + React + Payload，生产 PostgreSQL、本地 SQLite，方向正确，暂不更换技术栈。
- 页面基础：首页、产品目录、产品详情、方案、企业、FAQ、新闻、知识、案例、联系、搜索、智慧农业、资料申请、质量保证和可持续发展预览已经存在。
- 数据基础：产品、首页、企业资料、新闻、知识、案例和 FAQ 已有 Payload 读取路径；富文本和多语言字段已建立。
- 主要缺口：参考站逐页面的状态对照、导航分组和悬停时序、首页媒体与模块顺序、产品详情的型号对照、真实素材尺寸裁切、移动端状态、正式 13 语言前台和询盘服务。
- 不能认定为完成的内容：示例数据、占位图片、隔离开发预览、局部浏览器检查和现有冒烟测试都不能代替整站复刻验收。

当前进度：阶段 0 的首页/共享布局基线已经覆盖 1440×900、1280×720、1051×720、1060×720、768×844、390×844 和 320×720；目录与一个画册产品详情已补做 320px 窄屏无溢出检查。阶段 1 共享导航、阶段 2 首页对照、阶段 3 产品主链路、阶段 4 内容中心、P1 生产后台/备份、P2 内容模型/公开安全门禁、参考链接与资料边界复验、2026-11-09 可读来源参数证据复验以及 P3-B 轻量独立系列/种植方式结构已完成对应范围验收；下一阶段仍是 P3-A 正式内容、多语言、询盘和 SEO/noindex。正式 claims、停产状态和最终翻译仍单独保持 owner-review。

## 推荐架构

采用“参考站观察层 + 共享 UI 层 + Payload 内容层 + 页面适配层”的四层结构：

1. 观察层记录参考页面的 DOM 顺序、computed 样式、断点、默认状态、悬停/展开/关闭状态和素材尺寸。
2. 共享 UI 层维护 Header、导航菜单、语言菜单、Footer、快捷入口、Hero、兴趣区、卡片、表格、询盘预览和富文本渲染。
3. Payload 内容层维护产品、分类、媒体、首页、企业、新闻、知识、案例、FAQ 和资源；页面只依赖稳定的领域数据类型。
4. 页面适配层为首页、目录、详情、方案和内容详情组合共享组件；任何业主资料不得直接写入组件模板。

## 分阶段执行

### 阶段 0：复刻基线冻结

- 选定桌面 1280×720、1051×720 和移动 390×844 三个固定视口。
- 为首页、产品目录、产品详情、方案、FAQ、企业、新闻、知识、案例各建立参考截图/DOM/交互检查表。
- 标记参考素材的来源和授权状态；继续使用示例素材时必须显示示例标识。
- 清理仅属于旧原型的临时 CSS 和重复组件，但保留用户已有未提交修改。

验收：每个页面都有“参考状态—本地状态—差异—下一步”记录。

### 阶段 1：共享导航与布局闭环

- 对齐参考站 Header 的左右分组、居中品牌、搜索、语言和联系入口。
- 对齐 Products、Growing Practice、Crop Guide、Smart Farming、Corporate、Insights 的菜单分组。
- 逐项验证鼠标进入、面板保持、移出关闭、键盘 Enter/Escape、焦点返回和移动菜单。
- 解决 1051、1280 和移动断点下的遮挡、溢出和入口失效。

验收：导航状态矩阵通过，所有已开放链接可到达，未开放链接显示待建设而不产生 404。

### 阶段 2：首页和内容模块复刻

- 按参考站顺序复核轮播、兴趣切换、精选内容、产品推荐、企业主题、知识、案例、新闻、订阅和 Footer。
- 先完成结构、间距、字号、颜色、图片比例和滚动行为，再替换业主素材。
- 统一英文、中文、法语和西语开发预览的缺译策略。

验收：三个固定视口的模块顺序、关键尺寸、轮播和兴趣切换状态可复现。

### 阶段 3：产品导购主链路

- 复核目录分类卡、筛选、搜索、分页、语言切换和直接访问。
- 复核详情页横幅、产品信息、参数表、相关产品、知识入口、经销商入口和询盘预览。
- 等用户确认多图、任意型号对照表和参数缺译策略后再扩展数据结构。

验收：示例数据与 Payload 数据均能完成列表—详情—关联内容链路，缺译不回退错误语言。

### 阶段 4：方案与内容中心

- 完成方案/作物指南的章节导航、阶段、营养、产品关系和资源占位。
- 复核新闻、知识、案例的列表、搜索、作者/关键词筛选、分页、富文本、媒体和内部链接。
- 对每种语言验证详情不存在时 404，缺译只显示待补充。

验收：富文本标题、列表、图片、外部链接和内部本地化链接均能保存、渲染和搜索。

### 阶段 5：后台和真实资料接入

- 先录入少量真实产品、媒体、企业资料、首页内容、FAQ 和一篇真实文章，逐项核对前台；当前空库导入脚本已提供这些示例记录。
- 再执行批量导入、PostgreSQL 迁移、媒体持久化、备份和恢复演练。
- 业主确认询盘收件渠道后，才启用表单提交、邮件或工单集成。

### 阶段 6：上线验收

- 生产 PostgreSQL、域名、服务器、环境变量、媒体存储和备份。
- 真实设备、多语言、SEO/noindex 切换、无障碍、错误页、性能和回滚检查。
- 完成上线前问题清单，未通过项不得标记为完成。

## 技术和数据原则

- 页面组件不写死产品事实；事实只来自 Payload 或明确标记的示例源。
- 语言代码和 URL 前缀统一由共享路由层处理。
- 富文本内部链接只能指向存在且已开放的本地化实体。
- 参考站只用于学习布局和交互；品牌、文字、图片和视频必须使用业主授权或明确标记的示例。
- 每项视觉结论必须绑定视口和状态；一次截图不能证明整站完成。
