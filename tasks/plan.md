# 阶段计划

1. 规格：建立范围、验收及未决事项；按确认结果更新。
2. 调研：盘点参考站公开页面、状态、响应式和限制；形成 URL 与页面类型清单。
3. 技术验证：审查候选复刻工具、依赖与许可；用代表页面验证质量；比较技术路线并确认架构。
4. 原型：完成确认的主要页面类型和交互，逐页对照与记录差异。
5. 数据与多语言：使用示例数据打通列表、详情、筛选和语言切换，验证刷新及直接访问。
6. 真实内容：经业主审核后导入资料；按确认方案实现内容维护和询盘。
7. 验收：验证关键流程、移动端、SEO、性能与部署准备，形成问题清单；生产上线另行确认。

阶段 1–4 可与业主资料收集并行。架构选择、真实资料与正式发布分别依赖用户确认。每阶段记录实际结果，未验证项保持未验证。
